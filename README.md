# brandubh — 爱尔兰 7×7 tafl 棋

原创小项目：爱尔兰古棋 Brandubh 的极简实现。国王带 4 守卫突围到棋盘四角即胜；8 名攻方围杀国王（四面包围）即胜。纯 Python 标准库。

## 玩法

- 7×7 棋盘，攻方▲先手
- 全部棋子走车线（横竖任意格，不可跳子）
- 王座✛只有国王能进；角落◇只有国王能进，进角即胜
- 夹吃：把敌子夹在己方两子之间（或己方子+王座，王座对攻方敌对）即吃掉
- 王被四面攻子包围即被擒（王座不算包围格）
- 无棋可走判负

## 用法

```bash
python3 -m brandubh            # 人机交互（攻方先手，走法如 0333）
python3 -m brandubh --auto --games 10 --seed 42
```

## 诚实局限

- AI 只是 1 步贪心（吃子>王逃跑加成），不做深层搜索；tafl 攻方需要多步协同，贪心攻方偏弱
- 王座敌对规则采用简化版（只对攻方敌对），各地 tafl 变体规则本就不同
- 文本回合制，无图形/存档/悔棋；Python 3.10+
